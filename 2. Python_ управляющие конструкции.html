Python: управляющие конструкции

Условия, циклы while и for — все возможности и короткие примеры. Комментарий # → показывает результат.

if / matchwhileforbreak · continue · else · pass

Условный оператор if

Выполняет блок, только если условие истинно. Блок задаётся отступом (4 пробела).

if / elif / else

Проверяется сверху вниз, срабатывает первая истинная ветка. elif и else необязательны.

age = 17
if age < 14:
    print("ребёнок")
elif age < 18:
    print("подросток")   # → подросток
else:
    print("взрослый")

Вложенные условия

Блок if можно вложить в другой. Часто читается лучше, если объединить через and.

user, pwd = "ann", "123"
if user == "ann":
    if pwd == "123":
        print("вход")      # → вход
# то же самое:
if user == "ann" and pwd == "123":
    print("вход")

Операторы сравнения

Результат — True/False. Сравнения можно записывать цепочкой.

x = 5
x == 5   x != 3   x > 1   x <= 5   # → True
0 < x < 10        # → True (цепочка)
1 < x < 3 < 100  # → False

Логические: and, or, not

and/or вычисляются лениво и возвращают один из операндов, а не просто True/False.

not True            # → False
5 and 0             # → 0
0 or "по умолчанию" # → 'по умолчанию'
name = "" or "аноним"   # → 'аноним'

Принадлежность и тождество

in — есть ли элемент в коллекции или подстрока в строке. is — тот же объект (для None, True, False).

"a" in "cat"          # → True
3 not in [1, 2, 3]    # → False
x = None
if x is None:
    print("пусто")    # → пусто

Истинность значений

В условии можно писать любой объект. Ложными считаются: False, None, 0, 0.0, "", [], (), {}, set(), range(0). Всё остальное — истина.

items = []
if not items:
    print("список пуст")   # → список пуст
if "0":                    # непустая строка
    print("истина")        # → истина

Тернарный оператор

Выражение A if условие else B — условие в одну строку, возвращает значение.

n = 7
kind = "чёт" if n % 2 == 0 else "нечёт"
print(kind)   # → нечёт

Однострочный if и pass

Короткий блок можно писать на одной строке. pass — заглушка, когда блок должен быть, а действий пока нет.

if n > 0: print("плюс")
if n < 0:
    pass   # TODO: обработать позже

Оператор := (моржовый)

Присваивает значение прямо внутри условия (Python 3.8+).

data = [4, 8, 15]
if (k := len(data)) > 2:
    print(f"много: {k}")   # → много: 3

match / case (Python 3.10+)

Сопоставление с образцом: значения, | (или), условие if (guard), кортежи, _ — любой вариант.

def reply(cmd):
    match cmd:
        case "start" | "go":          # несколько значений
            return "запуск"
        case ("move", x, y):          # кортеж из 3 элементов
            return f"иду в {x},{y}"
        case int(n) if n < 0:         # тип + условие
            return "отрицательное"
        case _:                       # всё остальное
            return "неизвестно"

reply("go")             # → 'запуск'
reply(("move", 2, 5))   # → 'иду в 2,5'

Цикл while

Повторяет блок, пока условие истинно. Условие проверяется перед каждым проходом — меняйте переменную внутри, иначе цикл бесконечный.

Базовый цикл со счётчиком

Инициализация → условие → изменение.

i = 1
while i <= 3:
    print(i)
    i += 1
# → 1  2  3

break — выйти из цикла

Немедленно завершает ближайший цикл.

n = 0
while True:
    n += 1
    if n * n > 50:
        break
print(n)   # → 8

continue — к следующей итерации

Пропускает остаток тела и снова проверяет условие.

i = 0
while i < 6:
    i += 1
    if i % 2:        # нечётные пропускаем
        continue
    print(i)         # → 2  4  6

while … else

Ветка else выполняется, если цикл закончился сам (условие стало ложным), а не через break.

tries = 0
while tries < 3:
    tries += 1
else:
    print("попытки кончились")  # → выполнится
# при break — else пропускается

Бесконечный цикл с выходом

Типичный шаблон: ввод до тех пор, пока он не корректен.

while True:
    s = input("Число: ")
    if s.isdigit():
        break
    print("Это не число")
num = int(s)

while с условием по коллекции

Пустая коллекция — ложь, поэтому цикл идёт, пока в ней что-то есть. Подходит для стеков и очередей.

stack = [1, 2, 3]
while stack:
    print(stack.pop())   # → 3  2  1

while и :=

Читаем и проверяем значение за один шаг.

while (line := input("> ")) != "q":
    print("вы ввели", line)

Цикл for

Перебирает элементы любого итерируемого объекта: строки, списка, кортежа, множества, словаря, range, файла, генератора.

Перебор элементов

Переменная цикла получает по одному элементу.

for ch in "Py":
    print(ch)          # → P  y
for x in [10, 20]:
    print(x)           # → 10  20

range(): три формы

Генерирует числа; конец не включается.

range(4)          # 0 1 2 3
range(2, 5)       # 2 3 4
range(10, 0, -3)  # 10 7 4 1
for i in range(3):
    print(i)      # → 0  1  2

enumerate() — индекс + значение

Второй аргумент задаёт начальный номер.

for i, c in enumerate(["a", "b"], start=1):
    print(i, c)   # → 1 a  /  2 b

zip() — несколько последовательностей

Идёт параллельно, останавливается на самой короткой.

names = ["Аня", "Боря"]
ages = [20, 31]
for n, a in zip(names, ages):
    print(n, a)   # → Аня 20  /  Боря 31

Словарь: keys, values, items

По умолчанию цикл идёт по ключам.

d = {"a": 1, "b": 2}
for k in d: ...               # ключи
for v in d.values(): ...      # значения
for k, v in d.items():
    print(k, v)               # → a 1  /  b 2

reversed() и sorted()

Обход в обратном или отсортированном порядке, исходный список не меняется.

for x in reversed([1, 2, 3]):
    print(x)                  # → 3  2  1
for w in sorted(["b", "a"]):
    print(w)                  # → a  b

break, continue, else в for

else срабатывает, если break не было — удобно для поиска.

for n in [3, 5, 8]:
    if n % 2 == 0:
        print("чётное:", n)   # → чётное: 8
        break
else:
    print("чётных нет")

Вложенные циклы и распаковка

Внутренний цикл полностью проходит на каждый шаг внешнего. Кортежи распаковываются прямо в заголовке.

for i in range(1, 3):
    for j in range(1, 3):
        print(i * j, end=" ")   # → 1 2 2 4
pairs = [(1, "a"), (2, "b")]
for num, ch in pairs: ...

Звёздочка и счётчик «_»

_ — переменная, значение которой не нужно. * собирает остаток при распаковке.

for _ in range(3):
    print("hi")                 # 3 раза
for first, *rest in [(1, 2, 3)]:
    print(first, rest)          # → 1 [2, 3]

Генераторы списков (компактный for)

Цикл и условие в одном выражении. Есть версии для списков, множеств, словарей и генераторов.

squares = [x * x for x in range(5)]          # → [0, 1, 4, 9, 16]
evens   = [x for x in range(10) if x % 2 == 0]  # фильтр
label   = ["чёт" if x % 2 == 0 else "нечёт" for x in range(3)]
uniq    = {c for c in "hello"}               # множество
sq_map  = {x: x * x for x in range(3)}       # → {0: 0, 1: 1, 2: 4}
total   = sum(x for x in range(4))           # генератор → 6

Управление циклами: итог

Одинаково работает в while и в for.

continueПереходит к следующей итерацииСразу, где написан
elseБлок после циклаТолько если цикл не был прерван break
passНичего не делает, заполняет пустой блокВсегда
Совет: для цикла с известным числом шагов или по коллекции берите for, а когда число шагов заранее неизвестно — while.
