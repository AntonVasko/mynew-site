matplotlib

Базовая библиотека для графиков: полный контроль над каждым элементом. На ней построен seaborn и работает df.plot() в pandas.

Анатомия графика

  • Figure — всё полотно (окно или картинка).
  • Axes — область с графиком, осями, подписями. В одной Figure их может быть несколько.
  • Axis — ось с делениями.
  • Artist — любой нарисованный элемент: линия, текст, столбик.

Первый график (объектный стиль)

Рекомендуемый способ: fig, ax = plt.subplots().

x = [1, 2, 3, 4]
y = [1, 4, 9, 16]
fig, ax = plt.subplots(figsize=(6, 4))
ax.plot(x, y, marker="o", color="tab:blue", label="y = x²")
ax.set_title("Квадраты чисел")
ax.set_xlabel("x"); ax.set_ylabel("y")
ax.grid(True, alpha=0.3)
ax.legend()
plt.show()

Короткий стиль pyplot

plt.plot(x, y)
plt.title("Квадраты"); plt.xlabel("x"); plt.ylabel("y")
plt.show()

Виды диаграмм: Matplotlib + Pandas

Для всех примеров ниже используется один DataFrame. Matplotlib даёт полный контроль над графиком, а Pandas предоставляет удобную оболочку plot() поверх Matplotlib.

Общие данные для примеров

import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({
    "name":  ["Анна", "Борис", "Вера", "Глеб", "Даша", "Егор", "Жанна", "Илья"],
    "age":   [14, 15, 14, 16, 15, 14, 16, 15],
    "score": [78, 91, 67, 88, 95, 72, 84, 90],
    "group": ["A", "B", "A", "B", "B", "A", "C", "C"]
})

print(df)

1. Гистограмма — hist

Показывает распределение числовой величины: сколько значений попало в каждый интервал.

# Matplotlib
fig, ax = plt.subplots(figsize=(6, 4))
ax.hist(df["score"], bins=5, edgecolor="black")
ax.set_title("Распределение оценок")
ax.set_xlabel("Оценка")
ax.set_ylabel("Количество")
plt.show()
# Pandas
df["score"].plot.hist(
    bins=5,
    edgecolor="black",
    title="Распределение оценок"
)
plt.xlabel("Оценка")
plt.ylabel("Количество")
plt.show()

2. «Ящик с усами» — boxplot

Показывает медиану, квартили, диапазон данных и потенциальные выбросы.

# Matplotlib
fig, ax = plt.subplots(figsize=(5, 4))
ax.boxplot(df["score"])
ax.set_title("Разброс оценок")
ax.set_ylabel("Оценка")
plt.show()
# Pandas
df.boxplot(column="score")
plt.title("Разброс оценок")
plt.ylabel("Оценка")
plt.show()

3. Диаграмма рассеяния — scatter

Каждая точка — одно наблюдение. Используется для поиска связи между двумя числовыми признаками.

# Matplotlib
fig, ax = plt.subplots(figsize=(6, 4))
ax.scatter(df["age"], df["score"], alpha=0.8)
ax.set_title("Возраст и оценка")
ax.set_xlabel("Возраст")
ax.set_ylabel("Оценка")
plt.show()
# Pandas
df.plot.scatter(
    x="age",
    y="score",
    alpha=0.8,
    title="Возраст и оценка"
)
plt.show()

4. Круговая диаграмма — pie

Показывает доли категорий в одном целом. Лучше использовать для небольшого числа частей.

# Matplotlib
counts = df["group"].value_counts()

fig, ax = plt.subplots(figsize=(5, 5))
ax.pie(
    counts.values,
    labels=counts.index,
    autopct="%1.0f%%"
)
ax.set_title("Распределение по группам")
plt.show()
# Pandas
counts = df["group"].value_counts()

counts.plot.pie(
    autopct="%1.0f%%",
    ylabel="",
    title="Распределение по группам"
)
plt.show()

5. Вертикальная столбчатая диаграмма — bar

Удобна для сравнения категорий. Например, можно сравнить средний результат по группам.

# Matplotlib
avg = df.groupby("group")["score"].mean()

fig, ax = plt.subplots(figsize=(6, 4))
ax.bar(avg.index, avg.values)
ax.set_title("Средняя оценка по группам")
ax.set_xlabel("Группа")
ax.set_ylabel("Средняя оценка")
plt.show()
# Pandas
avg = df.groupby("group")["score"].mean()

avg.plot.bar(
    title="Средняя оценка по группам",
    xlabel="Группа",
    ylabel="Средняя оценка"
)
plt.show()

6. Горизонтальная столбчатая диаграмма — barh

Полезна, когда названия категорий длинные или нужно удобно сравнить несколько значений.

# Matplotlib
avg = df.groupby("group")["score"].mean().sort_values()

fig, ax = plt.subplots(figsize=(6, 4))
ax.barh(avg.index, avg.values)
ax.set_title("Средняя оценка по группам")
ax.set_xlabel("Средняя оценка")
ax.set_ylabel("Группа")
plt.show()
# Pandas
avg = df.groupby("group")["score"].mean().sort_values()

avg.plot.barh(
    title="Средняя оценка по группам",
    xlabel="Средняя оценка",
    ylabel="Группа"
)
plt.show()

Полезная схема: Pandas → Matplotlib

Методы визуализации Pandas не являются отдельной системой рисования: при обычном использовании они строят график средствами Matplotlib. Поэтому после plot() можно продолжать настраивать рисунок через plt или объект Axes.

fig, ax = plt.subplots(figsize=(7, 4))

df.groupby("group")["score"].mean().plot.bar(
    ax=ax,
    title="Средняя оценка"
)

ax.set_xlabel("Группа")
ax.set_ylabel("Средняя оценка")
ax.grid(axis="y", alpha=0.3)

plt.show()

Надстройка над matplotlib для статистических графиков. Работает с DataFrame: достаточно указать столбцы, а группировку, цвета и сглаживание seaborn делает сам.

Сетка по группам (figure-level)

Функции relplot, displot, catplot создают целую фигуру и сами раскладывают панели по col и row.

Два уровня функций

  • Axes-level (scatterplot, boxplot, heatmap…) рисуют на заданной области: параметр ax=, возвращают Axes.
  • Figure-level (relplot, displot, catplot, pairplot) создают свою фигуру и возвращают сетку.
fig, axs = plt.subplots(1, 2, figsize=(10, 4))
sns.histplot(data=df, x="body_mass_g", ax=axs[0])
sns.boxplot(data=df, x="species", y="body_mass_g", ax=axs[1])

Правила хорошего графика

  • Заголовок, подписи осей и единицы измерения.
  • Не обрезайте ось Y у столбцов: это искажает сравнение.
  • Мало цветов и логичные: один цвет — одна категория.
  • Палитра colorblind или viridis.
  • Избегайте 3D и лишних эффектов.
  • Подписывайте источник данных.

Визуализация и анализ данных (EDA)

Разведочный анализ (EDA) — первое знакомство с данными. Графики показывают то, что не видно в таблице: пропуски, выбросы, перекосы, связи.

Пример: быстрый EDA на данных «Титаника»

import seaborn as sns, matplotlib.pyplot as plt

df = sns.load_dataset("titanic")
df.info(); print(df.describe())

fig, axs = plt.subplots(2, 3, figsize=(15, 8), constrained_layout=True)
sns.heatmap(df.isna(), cbar=False, ax=axs[0, 0]);          axs[0, 0].set_title("Пропуски")
sns.countplot(data=df, x="survived", ax=axs[0, 1]);        axs[0, 1].set_title("Баланс классов")
sns.histplot(data=df, x="age", hue="survived", kde=True, ax=axs[0, 2]); axs[0, 2].set_title("Возраст")
sns.barplot(data=df, x="sex", y="survived", hue="pclass", ax=axs[1, 0]); axs[1, 0].set_title("Доля выживших")

Что находят графики

  • Пропуски → нужно решить: заполнить медианой, удалить, добавить признак «был пропуск».
  • Выбросы → ошибки данных или редкие случаи; влияют на линейные модели и KNN.
  • Дисбаланс классов → accuracy вводит в заблуждение, нужны precision/recall.
  • Сильная корреляция признаков → один можно убрать.
  • Утечка данных → признак почти идеально коррелирует с целью, он не будет известен в реальности.

Токен и лимиты

Без токена доступно примерно 60 запросов в час, с токеном — 5000. Поиск ограничен отдельно (меньше запросов в минуту). Токен создают в GitHub: Settings → Developer settings → Personal access tokens. Для публичных данных права не нужны. Хранить токен нужно в переменной окружения, а не в коде и не в репозитории.

export GITHUB_TOKEN=ваш_токен              # Linux / macOS
$env:GITHUB_TOKEN="ваш_токен"              # Windows PowerShell
gh_get("/rate_limit")["resources"]["core"]
# {'limit': 60, 'remaining': 57, 'reset': 1760000000}

Вспомогательная функция

import os, requests
API = "https://api.github.com"
HEADERS = {"Accept": "application/vnd.github+json"}
if os.getenv("GITHUB_TOKEN"):
    HEADERS["Authorization"] = f"Bearer {os.environ['GITHUB_TOKEN']}"

def gh_get(path, **params):
    r = requests.get(API + path, headers=HEADERS, params=params, timeout=15)
    r.raise_for_status()           # 404, 403 (лимит) → исключение
    return r.json()

GitHub считает статистику не сразу: первый ответ может быть 202. Нужно подождать и повторить.

import time
def commit_activity(owner, repo, tries=6):
    for _ in range(tries):
        r = requests.get(f"{API}/repos/{owner}/{repo}/stats/commit_activity",
                         headers=HEADERS, timeout=15)
        if r.status_code == 202:
            time.sleep(2); continue
        r.raise_for_status()
        return r.json()
    return []

Пагинация

Один ответ — максимум 100 элементов. Для остальных запрашивают следующие страницы.

def gh_pages(path, **params):
    params.setdefault("per_page", 100)
    out, page = [], 1
    while True:
        chunk = gh_get(path, page=page, **params)
        out += chunk
        if len(chunk) < params["per_page"]:
            break
        page += 1
    return out
contributors = gh_pages("/repos/pallets/flask/contributors")

Кэширование и этика

  • Сохраняйте ответ, чтобы не тратить лимит при каждом запуске.
  • Обрабатывайте 403 (лимит) и 404 (нет репозитория).
  • Не опрашивайте API в цикле без пауз.
from pathlib import Path

Безопасность и скорость

  • |safe применяйте только к HTML, который создали сами, не к тексту пользователей.
  • На сервере: matplotlib.use("Agg") или Figure, а после использования plt.close(fig).
  • Много точек (десятки тысяч): px.scatter(..., render_mode="webgl") или сократите данные.
  • Кэшируйте графики и ответы внешних API.
  • Готовые платформы: Dash, Streamlit, Bokeh.

Проект 4: веб-дашборд на Flask из трёх библиотек

Страница http://127.0.0.1:5000/?org=pallets: два статических графика (matplotlib и seaborn, base64) и один интерактивный (Plotly). Название организации можно менять в форме.

import base64, io, os, re
import pandas as pd, requests, seaborn as sns
import plotly.express as px
from flask import Flask, render_template_string, request
from matplotlib.figure import Figure

app = Flask(__name__)
HEADERS = {"Accept": "application/vnd.github+json"}
if os.getenv("GITHUB_TOKEN"):
    HEADERS["Authorization"] = f"Bearer {os.environ['GITHUB_TOKEN']}"

def load_repos(org):
    r = requests.get(f"https://api.github.com/orgs/{org}/repos",
                     params={"per_page": 100}, headers=HEADERS, timeout=15)
    r.raise_for_status()
    return pd.DataFrame(r.json())[["name", "language", "stargazers_count", "forks_count"]]

def png_b64(fig):
    buf = io.BytesIO()
    fig.savefig(buf, format="png", bbox_inches="tight")
    return base64.b64encode(buf.getvalue()).decode()

PAGE = """<!DOCTYPE html><html lang="ru"><head><meta charset="utf-8">
<title>{{ org }}</title>
<style>body{font-family:Arial;max-width:1000px;margin:20px auto;padding:0 12px}
.row{display:flex;gap:16px;flex-wrap:wrap}img{max-width:100%}</style></head>
<body><h1>Репозитории {{ org }}</h1>
<form><input name="org" value="{{ org }}"> <button>Показать</button></form>
<div class="row">
  <img src="data:image/png;base64,{{ img1 }}" alt="matplotlib">
  <img src="data:image/png;base64,{{ img2 }}" alt="seaborn">
</div>
{{ chart|safe }}
</body></html>"""

@app.route("/")
def dashboard():
    org = request.args.get("org", "pallets")
    if not re.fullmatch(r"[A-Za-z0-9-]{1,39}", org):      # защита от «странных» адресов
        return "Некорректное имя организации", 400
    try:
        df = load_repos(org)
    except requests.RequestException:
        return "Не удалось получить данные GitHub", 502

    top = df.nlargest(10, "stargazers_count")[::-1]
    f1 = Figure(figsize=(6, 4)); ax1 = f1.subplots()
    ax1.barh(top["name"], top["stargazers_count"])
    ax1.set_title("matplotlib: звёзды")

    f2 = Figure(figsize=(6, 4)); ax2 = f2.subplots()
    sns.countplot(data=df.dropna(subset=["language"]), y="language", ax=ax2)
    ax2.set_title("seaborn: языки")

    f3 = px.scatter(df, x="forks_count", y="stargazers_count", color="language",
                    hover_name="name", title="Plotly: звёзды и форки")
