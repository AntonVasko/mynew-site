Типы данных

Тип определяет, какие значения хранятся и что с ними можно делать. Узнать тип: type(x), проверить: isinstance(x, int).

Проверка типа

Python определяет тип по значению (динамическая типизация).

type(5)              # <class 'int'>
type("5")            # <class 'str'>
isinstance(2.5, float)  # True
isinstance(True, int)   # True

Приведение типов

Функции-конструкторы превращают значение в другой тип.

int("15")      # 15
int(3.9)       # 3 (отбрасывает дробную часть)
float("2.5")   # 2.5
str(100)       # '100'
bool(0)        # False
list("abc")    # ['a', 'b', 'c']
set([1, 1, 2]) # {1, 2}

Арифметика чисел

/ всегда даёт float, // — целое деление.

7 / 2      # 3.5
7 // 2     # 3
7 % 2      # 1 (остаток)
2 ** 10    # 1024
divmod(7, 2)  # (3, 1)
abs(-4)    # 4
round(2.675, 1)  # 2.7

Точность float

Дробные числа хранятся приблизительно. Для сравнения используйте round или math.isclose.

0.1 + 0.2             # 0.30000000000000004
round(0.1 + 0.2, 2)   # 0.3
2 ** 100              # int без ограничений

Изменяемые и неизменяемые

Изменяемые (list, dict, set) правятся «на месте». Неизменяемые (int, str, tuple) создаются заново.

a = [1, 2]; a.append(3)   # a → [1, 2, 3]
t = (1, 2)
t[0] = 9    # TypeError

Литералы и разделители

1_000_000    # 1000000 (подчёркивания для чтения)
0xFF         # 255 (16-ричное)
0b101        # 5 (двоичное)
0o17         # 15 (восьмеричное)
1.5e-3       # 0.0015

Переменные

Переменная — это имя, привязанное к объекту в памяти. Оператор = не копирует значение, а связывает имя с объектом.

Создание

Объявлять тип заранее не нужно. Имя можно привязать к другому типу.

age = 25          # int
name = "Анна"     # str
age = "двадцать"  # теперь str
del age           # удалить имя

Правила имён

Допустимы буквы, цифры и _. Нельзя начинать с цифры, использовать пробелы, дефисы и ключевые слова. Регистр важен.

user_1 = 1     # верно
_tmp = 2       # верно
1user = 3      # SyntaxError
my-var = 4     # SyntaxError
class = 5      # SyntaxError
Age != age     # разные имена

Стиль имён (PEP 8)

Договорённости, которые не проверяет интерпретатор, но ждут от кода.

user_name = "ann"   # snake_case: переменные
MAX_SIZE = 100      # КОНСТАНТЫ
_hidden = 1         # «внутреннее» имя
__x = 2             # защита имени в классе

Ключевые слова

Зарезервированы языком, использовать как имена нельзя. Полный список:

import keyword
print(keyword.kwlist)
# False None True and as assert async await
# break class continue def del elif else except
# finally for from global if import in is
# lambda nonlocal not or pass raise return
# try while with yield

Присваивание

Несколько имён одним оператором, обмен значений без временной переменной.

a, b = 1, 2        # два значения сразу
x = y = 0          # одно значение двум именам
a, b = b, a        # обмен: a=2, b=1
first, *rest = [1, 2, 3]   # 1 и [2, 3]

Составное присваивание

Короткая запись «изменить и сохранить».

n = 10
n += 5    # 15
n -= 3    # 12
n *= 2    # 24
n //= 5   # 4
n **= 2   # 16
s = "a"; s += "b"   # 'ab'

Имя — это ссылка

Два имени могут указывать на один изменяемый объект. Для независимой копии используйте .copy().

a = [1, 2]
b = a
b.append(3)
print(a)     # [1, 2, 3] — a тоже изменился
c = a.copy()   # независимая копия
id(a) == id(b) # True: один объект

Ввод и вывод

input() всегда возвращает строку. print() принимает sep и end.

name = input("Имя: ")
print("Привет,", name)
print(1, 2, 3, sep="-")      # 1-2-3
print("a", end="")           # без переноса

Работа со строками

Строка (str) — неизменяемая упорядоченная последовательность символов. Методы возвращают новую строку.

Создание и экранирование

a = 'одинарные'
b = "двойные"
c = """несколько
строк"""
d = "Он сказал: \"привет\"\n"   # \n перенос
e = r"C:\new\file"   # raw: \ как есть
"Py" "thon"          # 'Python' (склейка)

Индексы и срезы

Индексация с 0, с конца — отрицательные. Срез [старт:стоп:шаг], стоп не включается.

s = "Python"
s[0]       # 'P'
s[-1]      # 'n'
s[1:4]     # 'yth'
s[:2]      # 'Py'
s[::2]     # 'Pto'
s[::-1]    # 'nohtyP' (разворот)

Операции

"ab" + "cd"     # 'abcd'
"ab" * 3        # 'ababab'
len("Привет")   # 6
"th" in "Python"   # True
"a" < "b"        # True (по коду символа)
ord("a"), chr(98)  # (97, 'b')

Регистр и очистка

"hello".upper()       # 'HELLO'
"HeLLo".lower()       # 'hello'
"hello world".title() # 'Hello World'
"hello".capitalize()  # 'Hello'
"  hi  ".strip()      # 'hi'
"xxhixx".strip("x")   # 'hi'
"Ab".swapcase()       # 'aB'

split и join

split режет строку на список, join собирает обратно.

"a b  c".split()       # ['a', 'b', 'c']
"1,2,3".split(",")     # ['1', '2', '3']
"-".join(["a", "b"])   # 'a-b'
"".join(["x", "y"])    # 'xy'
"a\nb".splitlines()    # ['a', 'b']

Поиск и замена

s = "banana"
s.find("an")      # 1 (или -1, если нет)
s.index("an")     # 1 (или ValueError)
s.count("a")      # 3
s.replace("a", "o")   # 'bonono'
s.startswith("ba")    # True
s.endswith("na")      # True

Проверки содержимого

"123".isdigit()    # True
"abc".isalpha()    # True
"ab1".isalnum()    # True
"abc".islower()    # True
"  ".isspace()     # True

Выравнивание

"7".zfill(3)         # '007'
"hi".center(6, "*")  # '**hi**'
"hi".ljust(5, ".")   # 'hi...'
"hi".rjust(5)        # '   hi'

Форматирование: f-строки, format, %

f-строка — самый удобный способ: внутри {} можно писать выражения и спецификации формата.

name, pi, n = "Аня", 3.14159, 1234567
f"Привет, {name}!"          # 'Привет, Аня!'
f"{pi:.2f}"                 # '3.14'  (2 знака)
f"{n:,}"                    # '1,234,567'
f"{5:03d}"                  # '005'
f"{name:>6}|{name:<6}|{name:^6}"   # '   Аня|Аня   | Аня '
f"{2 + 3 = }"               # '2 + 3 = 5' (отладка)
"{} и {}".format("a", "b")  # 'a и b'
"%s: %d" % ("x", 5)         # 'x: 5' (старый стиль)

Вложенность и лаконичные конструкции

Python позволяет подставлять вызов функции прямо в аргумент другой и цеплять методы. Читается изнутри наружу.

Ввод числа в одну строку

Вместо трёх строк — один вложенный вызов.

# длинно:
s = input()
n = int(s)
# коротко:
n = int(input())
x = float(input("Вес: "))

Несколько чисел с одной строки

input().split() даёт список строк, map применяет int к каждой.

# ввод: 3 5
a, b = map(int, input().split())
print(a + b)    # 8
# ввод: 4 1 9
nums = list(map(int, input().split()))   # [4, 1, 9]

Цепочка методов

Каждый метод строки возвращает строку, поэтому вызовы можно соединять точкой.

cmd = input().strip().lower()
# "  START " → 'start'
"a,b".upper().split(",")   # ['A', 'B']
" x ".strip().center(5, "-")  # '--x--'

Вложенные вызовы

Результат внутренней функции сразу передаётся во внешнюю.

len(str(2 ** 100))      # 31 — цифр в числе
sum(map(int, "12345"))  # 15 — сумма цифр
max(len(w) for w in ["a", "abc"])  # 3
abs(int(input()))       # модуль введённого

Встроенные функции вместо кода

Готовые функции заменяют ручные вычисления.

nums = [4, 1, 9]
sum(nums)        # 14
min(nums)        # 1
max(nums)        # 9
sorted(nums)     # [1, 4, 9]
len(nums)        # 3
sum(nums) / len(nums)   # среднее 4.666…

Компактный вывод

Звёздочка распаковывает список в аргументы print.

nums = [1, 2, 3]
print(*nums)                # 1 2 3
print(*nums, sep=", ")      # 1, 2, 3
print(" ".join(map(str, nums)))  # 1 2 3
print(f"Сумма: {sum(nums)}")     # Сумма: 6

Цепочка сравнений и значение по умолчанию

Условия записываются без and, а or подставляет запасное значение.

x = 5
0 < x < 10          # True
a = b = c = 0       # одно значение трём именам
name = input() or "аноним"   # если пусто → 'аноним'

Распаковка

Раскладывает последовательность по именам за один шаг.

x, y = (10, 20)
h, m = map(int, "12:30".split(":"))   # 12, 30
first, *mid, last = [1, 2, 3, 4]      # 1, [2, 3], 4
_, b = "a b".split()                  # _ — не нужно

Принцип вложенности структур

Списки, кортежи и словари можно класть друг в друга. К значению обращаются цепочкой индексов и ключей, слева направо.

matrix = [[1, 2, 3], [4, 5, 6]]
matrix[1][2]            # 6 — строка 1, столбец 2

user = {"name": "Аня", "langs": ["ru", "en"], "addr": {"city": "Москва"}}
user["langs"][0]        # 'ru'
user["addr"]["city"]    # 'Москва'
user.get("age", 0)      # 0 — безопасно, если ключа нет

data = {"users": [{"id": 1, "tags": ("a", "b")}]}
data["users"][0]["tags"][1]   # 'b'
len(matrix[0]), len(user)     # (3, 3)
Совет: если вложенный вызов стал трудно читать, разбейте его на два-три шага с понятными именами переменных.
